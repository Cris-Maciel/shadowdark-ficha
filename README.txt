SHADOWDARK - FICHA PT-BR (PROTÓTIPO 0.1)

Objetivo
- Somente a primeira página da ficha enviada.
- Aparência da própria ficha como fundo.
- Todos os campos preenchíveis.
- Nenhuma rolagem, cálculo ou automação.
- Salvamento automático no navegador (localStorage).

TESTE RÁPIDO NO COMPUTADOR
1. Extraia esta pasta.
2. Abra index.html no navegador.
3. Clique nos espaços da ficha e digite.
4. Feche e abra novamente: os dados continuam salvos no mesmo navegador.

USAR NO OWLBEAR RODEO
A extensão precisa ser servida por uma URL HTTP/HTTPS. Durante testes locais, você pode
servir esta pasta com um servidor web simples; para uso normal, publique a pasta em um
serviço estático (por exemplo, GitHub Pages) e use a URL final de manifest.json ao adicionar
a extensão ao perfil do Owlbear Rodeo.

IMPORTANTE
Nesta versão, os dados ficam apenas no navegador/dispositivo em que foram digitados.
Não há sincronização entre computadores nem entre jogadores.
